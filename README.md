## 🛠 技术仿真工具 (Technical Simulation)
我们提供了一个简单的 Python 脚本，用于计算在自由空间中的信号传播损耗，帮助工程师评估屏蔽器的覆盖范围。

We provide a Python script to calculate Free Space Path Loss (FSPL) to help engineers evaluate the effective range of a jammer.



### 理论公式 (Theoretical Formula)
信号在空间中的传播损耗计算公式如下：

$$FSPL(dB) = 20 \log_{10}(d) + 20 \log_{10}(f) + 20 \log_{10}(\frac{4\pi}{c})$$

其中 $d$ 为距离，$f$ 为频率，$c$ 为光速。
